# Corbelle CDO Simulator

An interactive, single-file prototype that puts leaders under the pressure of six CDO-level data decisions.

## Run locally

Open `dist/index.html` in a browser. No build step or dependencies are required.

## Current direction

The experience opens with **The Board Is Waiting**: six decisions, forty-eight hours, no CDO. It is designed to make decision ownership, not dashboard volume, the urgent problem.

The next product iteration is to replace the placeholder debrief profile with a detailed visual diagnostic, including a radar chart and specific implications for the buyer.
